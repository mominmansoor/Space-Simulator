# Space Simulator

> 🚧 **Being revamped.** A big update is on the way, so expect things here to change a lot soon.

## What it is

An interactive 3D solar system that runs in your browser. The Sun sits in the middle, the planets orbit around it, and you can fly the camera around and click a planet to follow it.

The current version is all about the visuals: a custom shader sun, planet textures painted in code, glowing atmospheres and an asteroid belt between Mars and Jupiter.

## What's coming

The revamp is about making gravity the centre of the project, built around Einstein's field equations instead of just pretty orbits. The rest will get rebuilt along the way too.

More details here once the update lands.

## Running the current version

```bash
git clone https://github.com/mominmansoor/Space-Simulator
cd Space-Simulator
npm install
npm run dev
```

Then open the address Vite prints, usually http://localhost:5173.

Built with React, Three.js (React Three Fiber) and Vite.
